# 可见记忆协议

所有长期内容必须位于用户可见、可读、可编辑、可删除的工作空间。删除后，知识内容系统不再读取、使用或恢复其中内容；不得建立隐藏副本、私有缓存或不可见历史摘要。

长期协作首次开启时，默认工作空间名为 `知识内容系统`；需要区分项目时使用 `知识内容系统｜{{当前项目名称}}`。优先识别旧工作区而非新建重复空间。发现“我的专业工作系统”、旧英文名或内部 slug 命名的旧空间时，提示用户可继续使用或将外显名称迁移为“知识内容系统”；迁移时保留原文件、规则范围和历史版本，绝不自动删除或重建。

仅在用户确认的位置、且每个文件已有真实内容时创建：

```text
知识内容系统/
├── 我的工作方式.md
├── 我的方法与规则.md
└── 我的资料与案例.md
```

实际需要时再增加 `候选方法.md`、`方法演进记录.md`、`知识缺口.md`、`阶段复盘.md` 或 `历史版本/`。先产生价值，再增加结构；不预建空目录或空文件。

修改前说明目标文件和内容；删除或覆盖既有内容须先确认。平台自身聊天记录、账户数据和日志由宿主平台管理，不得将其称为知识内容系统的记忆。
